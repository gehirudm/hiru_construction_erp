# Construction ERP

Planning documentation for an ERPNext-based system for a construction business managing several projects at once.

The current [requirements baseline](docs/requirements.md) captures the pilot scope, chosen defaults, and details to validate before live use. Milestone devlogs are kept locally in `devlogs/` and excluded from Git. No ERPNext instance or application code has been set up yet.

## Working agreement

- Review and revise the pilot baseline as real project workflows become available.
- At each completed milestone, commit the relevant repository changes and add a new local, numbered devlog describing what was delivered, how it was built, the work performed, validation, and the milestone achieved.
- Keep proposed future milestones in the requirements draft until their scope is agreed.
